vraag 2:

Wat doet de attribuut “defer” in de script tag. antwoord: De tag defer in de script tag van HTML Java is een attribuut dat de browser kan achterhalen of het script extra inhoud zal toevoegen aan het HTML document. Dit is belangrijk omdat het de browser kan laten weten dat het script niet tijdens het maken van de pagina moet worden uitgevoerd. De browser moet dan geen rekening houden met het script tijdens het maken van de pagina. Het is belangrijk om de tag defer met een waarde te geven, zoals "defer", om de juiste oplossing te bieden voor de browser.
